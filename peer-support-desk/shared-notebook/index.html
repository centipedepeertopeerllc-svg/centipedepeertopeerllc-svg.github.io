📓 Our Shared Notebook Pad

The shared pad between the CEO and Tom. One notepad for Centipede's program work, shared by Levi Spears, Chief Executive Officer, and Tom Clark, Certified Peer Support Specialist.

The standing rule (CEO direction, November 21, 2026): whenever the CEO is working on the programs, everything about that program work goes on this notepad. The notepad is filed in its binder so it can be retrieved when needed; this Portal copy is the working surface, and both the CEO and Tom can read it and add entries here. Jarvis keeps the pad current.

Program-level work only. No client names, no client details, nothing confidential ever goes on this pad — client records live in the client dashboards and the locked client binders, which remain the official record.
